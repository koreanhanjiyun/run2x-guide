# 다른 팀이 이 가이드를 쓰는 법

## 1. 그냥 이 사이트에서 쓰기 (권장)
코드를 복제할 필요가 없습니다. 팀 데이터는 팀마다 따로 저장되고, 그 팀원만 볼 수 있습니다.

1. 사이트 오른쪽 위 상태 칩(예: "2026 시즌 · 로그인 안 됨")을 눌러 **구글 로그인**합니다.
2. 같은 창에서 **새 팀 이름**을 넣고 **팀 만들기** → 만든 사람이 그 팀의 첫 관리자가 됩니다.
3. 팀원은 로그인 → 칩 → **팀 선택 → 가입 신청**, 관리자가 칩 → **가입 신청 → 승인**합니다.
4. 인수인계: 관리자가 새 회장을 **관리자로** 지정한 뒤, 자기는 **관리자 내려놓기** 또는 **이 팀 나가기**. 마지막 관리자 1명은 내려오거나 나갈 수 없습니다.
5. 사이트 자체의 오류·제안은 칩 → **플랫폼 문의**로 보내면 사이트 개발자에게 전달됩니다.

## 2. 우리 팀 버전으로 따로 운영하기 (코드를 고쳐 쓰고 싶을 때)
라이선스(CC BY-NC 4.0)에 따라 출처("Run2X 19 한지윤", 원본 저장소 링크)를 밝히고, 고쳤다면 고쳤다고 표시하면 비영리로 쓸 수 있습니다.

1. 이 저장소를 **Fork** → Settings → Pages → Branch: main / (root).
2. 자기 팀의 Firebase 프로젝트를 새로 만듭니다: Firestore(Standard, 서울 asia-northeast3), Authentication → Google 사용, 승인된 도메인에 `내아이디.github.io` 추가.
3. 프로젝트 설정 → 웹 앱 등록 → `firebaseConfig` 를 `js/config.js` 에, 개발자 이메일을 `js/config.js` `developers` 와 `firestore.rules` `isDev()` 에 넣습니다.
4. Firestore → 규칙에 `firestore.rules` 를 붙여 넣고 게시합니다.
- 사이트 하단·변경 이력의 원작자 표기는 지우지 마십시오 (라이선스 조건).
