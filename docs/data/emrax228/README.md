# EMRAX 228HV LC — 데이터시트 그래프에서 읽은 값

출처: EMRAX 228 데이터시트 (A00, 관리자 제공 PDF) 1쪽의 그래프 그림 두 장. 그림(래스터)의 선 색을 따라 좌표를 읽은 값(디지타이징)이다. 숫자 표가 아니므로 근사값이다.

| 파일 | 내용 |
|---|---|
| `emrax228hv_torque_power.csv` | 0 ~ 6500 rpm, 100 rpm 간격. 최대 토크 · 최대 출력 · 연속 토크 · 연속 출력 |
| `emrax228hv_efficiency_map.csv` | 모터 효율 [%]. 첫 행 = 회전수 0 ~ 5500 rpm (250 간격), 첫 열 = 토크 0 ~ 250 N·m (10 간격) |
| `check_torque_power.png` | 원본 그래프 위에 읽은 점을 겹친 그림 |
| `check_efficiency_map.png` | 원본 효율 맵 위에 읽은 맵 값(숫자)과 88 · 92 % 보간 등고선(검은 선)을 겹친 그림 |
| `digitize_*.py` | 읽는 데 쓴 코드 (입력: PDF에서 `pdfimages -png` 로 뽑은 그림) |

## 확인

- 최대 · 연속 각각 출력 = 토크 × 각속도 가 0.5 % 안에서 맞음 (토크 곡선과 출력 곡선을 따로 읽었는데 서로 일치).
- 데이터시트 표 값과 비교: 최대 토크 230 N·m (읽은 값 230.0), 최대 출력 124 kW (124.4), 연속 토크 130 N·m 표기는 그래프 약 112 N·m 와 다름 — 표는 냉각 조건별 최댓값, 그래프는 이 조건의 곡선으로 보임 (확실하지 않음).

- 2026-11-05 고침: 처음 읽을 때 선 색을 색마다 따로(거리 < 40) 골라, 96 % 파란 선의 번진 화소가 86 % 청록 선으로도 잡혔다. 그래서 96 % 선 바로 위 5칸(100 N·m · 1750 rpm, 120 · 3750, 130 · 2000 ~ 2500)이 86 % 로 잘못 나왔다. 화소마다 가장 가까운 선 색 하나로만 분류하도록 고쳐 다시 읽었고, 그 5칸만 95.8 ~ 96.0 % 로 바뀌었다(나머지 칸은 0.05 % 안에서 같음).

## 가정 · 한계

- 그래프 제목이 **228HV LC** (설계 전압 710 V). 토크가 줄기 시작하는 회전수는 축전지 전압에 비례하므로, 팀 축전지 전압이 다르면 이 곡선을 그대로 쓸 수 없다.
- 효율 맵은 등고선 5개(86 · 90 · 94 · 95 · 96 %) 사이를 선까지의 거리로 선형 보간한 값이다. 96 % 선 안쪽은 가운데로 갈수록 96.5 % 까지 올렸다(추측). 86 % 선 바깥(낮은 회전수 · 낮은 토크 · 최대 토크 위)은 데이터가 없어 86 % 로 두었다(실제는 더 낮을 수 있음).
- 효율은 모터만의 값으로 보인다(인버터 제외, 추측).
- 회전수 · 토크 눈금 위치는 그림의 격자선으로 맞췄다. 그림 해상도(가로 약 750 ~ 940 px) 때문에 눈금 범위의 1 % 안팎 오차가 있다고 본다(추측).
